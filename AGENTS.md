# Инструкции по юридическому исследованию

При вопросах о законодательстве Республики Беларусь используй только первичные
документы BELAW на ilex.by. Правовые выводы по памяти, поисковым сниппетам,
вторичным материалам и другим сайтам запрещены.

1. Сначала определи минимальный перечень документов, норм и условий их
   применимости. Не переноси условия одной роли, альтернативы или статуса на
   другую.
2. Если прямая BELAW-ссылка известна, не ищи документ повторно. Иначе используй
   `search_ilex` не более двух раз для одного документа. Выдача нужна только для
   реквизитов и URL первичного BELAW.
3. При известных номерах норм используй `get_ilex_sections`. При неизвестных —
   `search_ilex_document`, затем получи установленные нормы точно. Не используй
   `bypass_cache=true` без прямой просьбы или подтверждённой ошибки кеша.
4. Норма считается неполученной, если инструмент отметил её как ненайденную,
   неоднозначную, обрезанную или не поместившуюся в лимит.
5. Для сложного, многодокументного вопроса, международного договора или
   возможной коллизии вызови `inspect_ilex_document` для каждого применимого
   документа. Получи найденные протоколы и связанные акты либо явно обоснуй их
   неприменимость.
6. Перед правовым выводом по такому вопросу обязательно вызови
   `validate_legal_research`, перечислив все применимые документы и нормы.
   Ответ по существу разрешён только при `complete=true`. При `complete=false`
   сначала устрани каждый пробел.
7. Проверяй статус, действующую редакцию, дату вступления нормы в силу, будущие
   изменения и последний вступивший в силу изменяющий акт, указанный в
   консолидированном тексте. Отдельно загружать изменяющий акт не нужно, если
   его реквизиты подтверждены BELAW и содержание не требуется.
8. Если неизвестный факт, договор, протокол, локальный акт или статус может
   изменить результат, дай только условный вывод и назови зависимость.
9. В ответе укажи вывод, условия и исключения, применённые нормы, статус и
   редакцию, последний подтверждённый изменяющий акт, прямые BELAW-ссылки,
   существенные допущения и неполученные данные.

Для простого вопроса по одной известной норме сохраняй быстрый маршрут:
`get_ilex_sections` → ответ. Не запускай проверку связанных документов без
признаков международного договора, отдельного протокола, коллизии или влияния
другого акта.
