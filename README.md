# belarus-legal-mcp

MCP-сервер для Claude Desktop, который добавляет инструменты для работы с белорусским законодательством:

- **pravo.by** — скачивание и поиск по PDF с автопроверкой актуальности редакции
- **ilex.by** — поиск и чтение документов через авторизованную сессию Chrome

## Инструменты

| Инструмент | Описание |
|-----------|---------|
| `crawl` | Скрапинг HTML-страницы → Markdown |
| `search_crawl` | Найти релевантные фрагменты на HTML-странице (нужно для объёмных карточек pravo.by — иначе результат может превысить лимит размера ответа) |
| `download_pdf` | Скачать PDF целиком (с кешем и проверкой редакции для pravo.by) |
| `search_pdf` | Найти релевантные фрагменты в PDF (~97% экономии контекста) |
| `search_ilex` | Поиск документов на ilex.by по запросу, включая тематические таблицы/классификаторы |
| `search_ilex_document` | Найти до 5 релевантных фрагментов в документе ilex.by; при явном номере статьи/пункта автоматически возвращается точный структурный элемент |
| `get_ilex_sections` | Пакетно получить точные статьи/пункты документа ilex.by по номерам |
| `inspect_ilex_document` | Проверить реквизиты документа и обнаружить связанные протоколы/изменяющие BELAW-документы без жёсткого реестра ссылок |
| `validate_legal_research` | Убедиться перед сложным правовым выводом, что все обязательные нормы действительно получены и связанные акты оценены |
| `crawl_authenticated` | Чтение страницы ilex.by через вашу сессию Chrome (headless) |
| `get_pdf_sections` | Пакетно получить точные статьи/пункты PDF по номерам |

## Установка

### macOS

```bash
# 1. Создать окружение
python3 -m venv ~/.claude/mcp_servers/crawl4ai_env
~/.claude/mcp_servers/crawl4ai_env/bin/pip install .
~/.claude/mcp_servers/crawl4ai_env/bin/playwright install chromium

# 2. Скопировать сервер
cp server.py ~/.claude/mcp_servers/crawl4ai_server.py
```

Добавить в `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "crawl4ai": {
      "command": "/Users/ИМЯ/.claude/mcp_servers/crawl4ai_env/bin/python",
      "args": ["/Users/ИМЯ/.claude/mcp_servers/crawl4ai_server.py"]
    }
  }
}
```

### Windows

```cmd
python -m venv %USERPROFILE%\.claude\mcp_servers\crawl4ai_env
%USERPROFILE%\.claude\mcp_servers\crawl4ai_env\Scripts\pip install .
%USERPROFILE%\.claude\mcp_servers\crawl4ai_env\Scripts\playwright install chromium
```

Добавить в `%APPDATA%\Claude\claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "crawl4ai": {
      "command": "C:\\Users\\ИМЯ\\.claude\\mcp_servers\\crawl4ai_env\\Scripts\\python.exe",
      "args": ["C:\\Users\\ИМЯ\\.claude\\mcp_servers\\crawl4ai_server.py"]
    }
  }
}
```

> Замените `ИМЯ` на ваше имя пользователя.

Команды `pip install .` нужно выполнять из папки этого проекта. Для проверки
изменений запустите:

```bash
python -m unittest discover -s tests -v
```

Перезапустить Claude Desktop.

## Использование

### Работа с pravo.by

```
Скачай документ: https://pravo.by/upload/docs/op/W21226212_1344459600.pdf
```

```
Найди в этом PDF всё про персональные данные:
url: https://pravo.by/upload/docs/op/W21226212_1344459600.pdf
query: персональные данные
```

Сервер автоматически:
- Кеширует PDF на диск (`~/.claude/mcp_servers/pdf_cache/`)
- При каждом обращении проверяет, не вышла ли новая редакция на pravo.by
- Уведомляет, если кеш был обновлён

### Работа с ilex.by

Нужна активная авторизованная сессия Chrome.

```
Найди на ilex: статья 169 трудовой кодекс
```

```
Открой документ: https://ilex-private.ilex.by/view-document/BELAW/219268/
```

Для точечного вопроса по конкретному документу — без загрузки полного текста:

```
Найди в этом документе про уведомление об отпуске:
url: https://ilex-private.ilex.by/view-document/BELAW/219268/
query: уведомление о начале отпуска
```

Если номера норм уже известны, выгоднее получить их одним пакетным вызовом:

```text
url: https://ilex-private.ilex.by/view-document/BELAW/219268/
sections:
  - статья 18
  - статья 261-3
```

Тематические поисковые инструменты по умолчанию возвращают не более 5
фрагментов и соблюдают мягкий бюджет 12 000 символов. Первая найденная норма
никогда не обрезается посередине; не поместившиеся элементы перечисляются в
ответе и могут быть запрошены отдельно.

Chrome при этом визуально не открывается — всё работает headless. Текст документа кешируется на диск; при каждом обращении сервер лёгким запросом (без экспорта в Word) проверяет дату редакции в заголовке страницы и обновляет кеш, если она изменилась — так же, как для pravo.by. Принудительно обновить: `bypass_cache: true`.

В пределах одного MCP-процесса авторизованный Chrome запускается один раз и
переиспользуется последующими вызовами. Операции выполняются последовательно в
отдельных вкладках, поэтому профиль не копируется и браузер не запускается
заново для каждой нормы. При завершении MCP временный профиль и Chrome
закрываются автоматически.

Положительная поисковая выдача ilex кешируется на один час без сохранения
пользовательского запроса в открытом виде. Кеш используется только для поиска
URL документа; редакция и текст нормы всё равно проверяются при чтении
первичного документа. На macOS рабочий профиль Chrome создаётся быстрым
copy-on-write-клоном APFS, а при его недоступности сервер автоматически
возвращается к обычному копированию.

### Контроль полноты сложного исследования

Для вопроса по нескольким документам, международному договору или возможной
коллизии используйте следующий маршрут:

```text
поиск документа → точное получение норм → inspect_ilex_document
→ получение или оценка связанных актов → validate_legal_research → ответ
```

Сервер ведёт внутри текущего MCP-процесса журнал фактически полученных норм.
Поэтому валидатор не засчитывает простое упоминание статьи, ненайденную норму
или норму, не поместившуюся в лимит ответа. Связанные документы ищутся по
реквизитам и текстовому сходству среди ранее полученных BELAW, а при
необходимости — через поиск ILEX; списки стран и номера соглашений в коде не
зашиты.

Для простого вопроса по одной известной статье дополнительная проверка не
нужна: сохраняется быстрый маршрут `get_ilex_sections → ответ`.

## Системный промпт

Актуальные инструкции для Codex находятся в [`AGENTS.md`](AGENTS.md). Они
добавляют обязательный контроль полноты для сложных вопросов и сохраняют
быстрый маршрут для одной известной нормы.

Системные инструкции не заменяют MCP-сервер: сервер предоставляет и проверяет
данные, а промпт определяет обязательный порядок их использования.

### Claude Desktop

Скопируйте следующий блок целиком в пользовательские инструкции Claude:

```text
При вопросах о законодательстве Республики Беларусь используй только первичные документы BELAW на ilex.by. Правовые выводы по памяти, поисковым сниппетам, вторичным материалам и другим сайтам запрещены.

1. Сначала определи минимальный перечень необходимых документов, норм и условий их применимости. Если норма содержит несколько ролей, статусов или альтернатив, отдельно проверь каждую из них. Не переноси ограничения одной альтернативы на другую.

2. Если прямая ссылка на документ BELAW уже известна, не выполняй повторный поиск. Если ссылки нет, используй search_ilex. Для одного документа допускается не более двух коротких предметных запросов. Результаты поиска используй только для определения реквизитов и URL первичного документа BELAW. Материалы BEPPN, BECMB, BEQUEST и другие вторичные документы нельзя использовать для правового вывода.

3. В выдаче отличай действующую редакцию от документа с будущими изменениями. Не применяй изменения, которые ещё не вступили в силу.

4. Если номера норм известны, обязательно используй get_ilex_sections. Несколько статей или пунктов одного документа запрашивай одним вызовом. Если номера неизвестны, используй search_ilex_document, чтобы установить применимые нормы, после чего получи их точный текст через get_ilex_sections. crawl_authenticated используй только когда точечного получения недостаточно и нужен полный текст. Один документ полностью загружай не более одного раза.

5. Не устанавливай bypass_cache=true без прямой просьбы пользователя или подтверждённого повреждения кеша. Сервер самостоятельно проверяет актуальность редакции.

6. Если инструмент сообщил, что норма не найдена, неоднозначна, обрезана или не помещена в лимит, считай её неполученной. Уточни номер либо запроси норму отдельно до подготовки ответа.

7. Для сложного, многодокументного вопроса, международного договора или возможной коллизии вызови inspect_ilex_document для каждого применимого документа. Получи найденные протоколы и связанные акты либо явно обоснуй их неприменимость. Для двусторонней нормы до её применения явно сопоставь фактические роли: первое государство, другое государство, резидентство, место деятельности и источник выплаты.

8. Перед правовым выводом по такому вопросу обязательно вызови validate_legal_research. Передай исходный вопрос пользователя дословно, перечисли все применимые документы и нормы и добавь related_assessments для каждого найденного связанного документа с выводом о применимости и кратким обоснованием. Ответ по существу разрешён только при complete=true. При complete=false сначала устрани каждый указанный пробел.

9. До вывода проверь статус и действующую редакцию документа, дату вступления применяемой нормы в силу, будущие изменения и последний вступивший в силу акт, изменивший применяемую норму, если он указан в тексте или метаданных первичного документа. Не загружай изменяющий акт отдельно, если его реквизиты подтверждены консолидированным текстом и содержание не требуется.

10. Проверь, могут ли устав, договор, протокол, локальный акт, статус лица или иные неизвестные обстоятельства изменить результат. Если неизвестный документ или факт может изменить вывод, дай только условный результат, назови зависимость и перечисли подтверждённые варианты.

11. Ответ по существу допускается только после получения текста каждой применяемой нормы из первичного документа BELAW. Если первичный текст или действующую редакцию получить невозможно, прекрати исследование и сообщи, какой документ, норма или инструмент недоступны.

12. В ответе укажи краткий вывод, существенные условия и исключения, применённые документы и нормы, статус и подтверждённую редакцию, последний изменяющий акт, если он подтверждён, прямые BELAW-ссылки, существенные допущения и неполученные данные, способные изменить вывод.

Для простого вопроса по одной известной норме сохраняй быстрый маршрут: get_ilex_sections → ответ. Не запускай проверку связанных документов без признаков международного договора, отдельного протокола, коллизии или влияния другого акта.

Без отдельного разрешения запрещены: pravo.by, etalonline.by, сайты государственных органов, consultant.ru, garant.ru, pravo.gov.ru, статьи, комментарии, форумы, поисковые сниппеты и другие вторичные источники.
```

## Как это устроено: ilex.by и виртуальный скроллинг

Большие документы на ilex.by рендерятся с виртуальным скроллом — в DOM браузера
всегда присутствует только видимая на экране часть, остальное подгружается и
выгружается по мере прокрутки. Из-за этого прямое чтение текста со страницы
(`page.inner_text()`) обрезает документ до нескольких первых экранов — для
документа на 1200+ пунктов можно получить лишь ~100 из них.

Решение: сервер кликает по кнопке «Экспорт в Word» на странице документа,
перехватывает скачивание получившегося `.rtf`-файла и конвертирует его в текст.
Это даёт полный документ вместо обрезанного фрагмента. На macOS конвертация
идёт через встроенный `textutil`; на других платформах — через библиотеку
`striprtf` (даёт менее точный результат на документах с крупными таблицами).

## Требования

- Python 3.10+
- Google Chrome (установленный, для `crawl_authenticated`, `search_ilex` и `search_ilex_document`)
- Подписка на ilex.by с активной сессией в Chrome (для ilex-инструментов)
- macOS — для наиболее точного извлечения текста документов ilex.by (`textutil`);
  на других ОС используется библиотека `striprtf` (`pip install striprtf`)

## Диагностика производительности

Сервер записывает длительность каждого MCP-вызова и дорогих этапов ilex в
`~/.claude/mcp_servers/logs/belarus_legal_mcp.jsonl`. В журнал не помещаются
тексты документов и поисковые запросы. Поле `since_previous_tool_ms` показывает
паузу между последовательными вызовами инструментов, а `duration_ms` — время
самого MCP и отдельных этапов Chrome, экспорта, кеша и извлечения нормы.
